# Complaint Management System (PHP)

## 📌 Project Description

This is a web-based Complaint Management System developed using PHP and MySQL.
It helps students to submit complaints and allows admin/faculty to manage them.

---

## 🚀 Features

* User Login & Signup
* Admin Dashboard
* Student Dashboard
* Faculty Dashboard
* Add Complaint
* View Complaints
* Contact Page

---

## 🛠️ Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript

---

## ⚙️ How to Run

1. Start XAMPP
2. Copy project folder to `htdocs`
3. Import database in phpMyAdmin
4. Open browser:
   `http://localhost/complaint-management-system`

---
